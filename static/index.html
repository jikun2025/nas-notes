登录轻签

输入账户名和密码（默认 admin / admin）登录。密码只在本机内存中用于解密，服务器只存哈希和密文。

填 NAS 的 IP 与端口，例如 192.168.5.10:28080。只有「登录并同步」会连它；留空则沿用上次保存的地址。

本机模式：便签只加密保存在这台手机上，不联网也能读写；需要多端同步时再连接 NAS。

密码丢失无法恢复。

危险操作：不可撤销
将永久删除服务器和本机上的全部便签、图片和录音，并重建空加密库。账户名和密码不会改变。

账户

账户名和密码可随时修改。密码同时用于解密便签：改密码时本机自动重新封装加密库，已有便签不受影响。

保存后旧会话立即失效，本机将用新账户自动重新登录。

便签始终先加密写入本机，断网也能读写。与 NAS 的同步只在你点「立即同步」时发生，不会在后台自动联网。
